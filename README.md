# UNRULYLOC.D NATION — Concept

A presentation-only website concept for a personal loctician brand.

## Purpose
This repository is **not the finished client website**. It is a visual prototype for client approval before production work begins.

## Concept direction
- Dark, editorial, premium loc-care aesthetic
- Mobile-first presentation
- Hair restoration
- Loc repairs
- Loc care
- Instant locs
- Hair growth oil and loc-care product showcase
- Featured work / transformation section
- About section
- Concept booking and social CTAs

## Notes
- Current photography is placeholder concept imagery.
- Real client images, WhatsApp number, email, social links, prices and final copy are intentionally not wired yet.
- Booking/social buttons demonstrate interaction only.
- Product display is illustrative and does not include e-commerce.

## Files
- `index.html` — page structure
- `styles.css` — complete visual design and responsive layout
- `script.js` — mobile navigation and concept interaction feedback

Brand: **UNRULYLOC.D NATION**
